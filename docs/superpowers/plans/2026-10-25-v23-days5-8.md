- Lock source/model/feature/event-code hashes, time mapping, masks and source bout eligibility before model deserialization. Immutable protocol receipt; inference refuses missing/mismatched lock or existing outputs.

Exclude whole predictions crossing coverage/identity boundaries and record each exclusion; never clip events. Excluded expert bouts censor both streams with overlap closure. This differs from earlier development mask-before-detection evaluation and must be disclosed.
